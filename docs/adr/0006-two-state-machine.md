# 0006. 状态机收敛为两态

- 状态：已接受（**其中「鼠标契约全局唯一」一条已被 [ADR-0007](0007-list-does-not-dismiss-on-mouse.md) 修订**：书单开着时鼠标不参与收场）
- 日期：2026-09-22
- 取代：对 ADR-0005 中「状态机的变化」一节的修订

## 背景

ADR-0005 决定只保留伪装阅读，但当时把状态机画成了**三态**：`closed` → `disguise`
（紧急隐藏，纯工作痕迹）→ `reading`（正文与工作痕迹交错），并让 `reading` 里的点击
**降级**到 `disguise` 而不是直接退出。

实测之后这条路被否掉了，理由是它把最慌的那一刻变复杂了：

- 三态意味着"点一下"的结果取决于当时在哪一态 —— 被撞见时没有时间去想现在是哪一态；
- `disguise` 态里"点击/按键任意一下退回真实界面"与 `reading` 态里"点击只降级"是**两套相反的鼠标契约**，
  同一个动作在不同状态下含义不同，这本身就是误操作的来源；
- 紧急隐藏态要额外维护一套"纯工作痕迹"的渲染路径，而它在真实使用中出现的机会极少。

真正的需求只有一条：**手一碰鼠标，屏幕上就没有小说了**。三态并没有让它更安全。

## 决定

状态机收敛为两态，鼠标契约全局唯一：

| 状态 | 语义 | 交互 |
| --- | --- | --- |
| `closed` | DSH 真实界面 | 快捷键 → `stream` |
| `stream` | 伪装内容流（正文与工作痕迹交错） | **鼠标移动 1px / 点击 / pointerdown → 立刻 `closed`**；快捷键也回 `closed` |

```
closed ──快捷键──▶ stream
   ▲                 │
   └─────────────────┘
     鼠标移动 / 点击 / 快捷键
```

要点：

- **没有中间态**。任何时候鼠标一动，直接回到 DSH 真实界面，不存在"降到某个更安全的伪装态"这一步。
- **键盘不退出**。`←` `→` `L` `↑` `↓` `空格` 全部留给阅读 —— 否则读到一半会被自己按没。
  滚轮同理（`wheel` 不在退出事件里）。
- `stream` 是**唯一**的阅读形态，不存在"书页模式"（ADR-0005 的结论不变）。

## 后果

- 视觉上少了一层退路：`stream` 就是最终的伪装形态，它必须自己站得住（正文与工作痕迹共用一套排版、
  工作痕迹取自真实会话、章节标题伪装成 `Read` 调用）。
- 交互上少了一个要记的东西：**手碰鼠标就消失**，不需要判断当前状态。
- ADR-0005 的其余结论（没有书页模式、正文走 AI 回复身份、章节行伪装成工具调用）全部继续有效。
