# ADR 0004 — 阅读进度锚定在"章内字符比例"，不存滚动像素

- 状态：已接受
- 日期：2026-09-22

## 背景

阅读器允许用户改字号、行距、窗口宽度。这些都是**重排**操作：同一段文字在不同设置下占据不同的屏幕高度。任何"记住你滚到哪儿"的方案都必须经受住重排。

## 决策

阅读进度由两部分组成：

1. **章节序号**；
2. **该章内的字符偏移占全章长度的比例**。

恢复进度时的做法是：进入该章，按比例反算目标字符位置，再映射到重排后的实际位置上。

附带规则：**当进度已在书的结尾附近（约 99% 以上）时，打开书不自动跳转**。

## 理由

1. 字符偏移是**与排版无关的量**。字号、行距、窗口宽度怎么变，同一段文字在两个设置下的字符偏移占比是稳定的，所以比例锚天然抗重排。
2. 存像素是最省事的做法，也是**阅读器最经典的 bug 来源**：改一次字号，下次打开就跳到完全不同的位置。
3. "结尾附近不自动跳转"解决的是同一条链上的第二个经典 bug：一本书读完后，每次打开都被甩到"全文完"，用户必须手动往回翻才能重读。

## 代价

- 恢复位置存在**半屏以内的误差**（比例无法精确到行，因为不知道重排后每行多少字）。这是可接受的：用户能立刻看出自己在哪。
- 需要把"字符偏移 ↔ 渲染位置"的换算实现正确，这部分逻辑必须被单元测试覆盖（它是本项目最容易静默出错的地方）。

## 被放弃的替代方案

- **滚动像素**：实现最简单，但完全不耐重排。
- **章内第 N 个段落**：段落是天然语义边界，重定位更精确；但部分网文存在超长无空行段落，届时会退化成"整章一个段落"，锚点失去意义。
