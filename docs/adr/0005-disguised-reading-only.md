# ADR-0005：唯一阅读形态就是伪装阅读（移除书页渲染）

- 状态：已接受（**其中「状态机的变化」一节已被 [ADR-0006](0006-two-state-machine.md) 取代**，其余仍然有效）
- 日期：2026-09-22
- 取代：ADR-0004 中关于"书页排版"的部分（进度锚点部分仍然有效）

## 背景

最初的设计把"伪装"和"阅读"做成了**两个互不相干的界面**：

- **书页阅读态**：42em 居中、衬线字体、大留白 —— 舒服，但一眼就是小说阅读器；
- **伪装壳**：等宽、全屏、逐行出现的假日志 —— 安全，但**不能读书**。

用户实际使用时立刻指出了问题："日志流现在和正文有很大的割裂"。更关键的是用户澄清了原始意图：

> 我一开始一直以为，你是要在伪装日志流中掺杂书籍内容。

也就是说，用户要的从来不是"两个界面 + 来回切换"，而是**屏幕上看起来是 AI 在生成内容，而那些内容就是小说正文**。

原设计的两个后果都不可接受：

1. **割裂**：读书页时是"另一个软件"，切到日志流又完全读不了，每次读书都要在两个世界之间跳；
2. **暴露**：书页形态本身就是最大的暴露面 —— 衬线、居中、大留白，任何人扫一眼都知道屏幕上是小说，而不是"AI 在干活"。

## 决策

**取消书页渲染。唯一的阅读形态是"伪装阅读"：正文以任务流的形态呈现，并与工作痕迹行交错。**

具体形态（自上而下）：

```
▸ analyze corpus                      2.4s   ok
  reading 42 files · 12,480 lines
  ⌨  ←/→ chapter · space page · l list
[3/512] 第一章 风起
  李四站在山巅，风从背后推来。
  他闭上眼，听见远处松涛如潮。
  ...
  grep -n "TODO" src/**.ts            0.8s   ok     ← 真实会话数据
  正文继续……
  [3/512] 12%
```

- 正文段落用**等宽字体**，与日志行同一套排版：这样"散文"和"工作痕迹"看起来是同一种东西。
- 工作痕迹行**来自真实会话数据**（ADR-0002 的取数方式不变），不是凭空编的模板 —— 编的日志最容易被一眼看穿。
- 章节标题伪装成 `[3/512] 第一章 风起` 这样的进度行。

## 状态机的变化

"能滚动阅读"与"任何交互都退回真实界面"**不能共存于同一个状态**，因此拆成两个：

| 状态 | 语义 | 交互 |
| --- | --- | --- |
| `closed` | DSH 真实界面 | —— |
| `disguise` | **紧急隐藏**：纯工作痕迹，没有任何正文 | **任何点击/按键立刻退回 `closed`**（保命路径，行为不变） |
| `reading` | **伪装阅读**：正文与工作痕迹交错 | 滚动/翻页/跳章 = 阅读；**点击 = 降级到 `disguise`** |

转换：

```
closed ──快捷键──▶ disguise ──快捷键──▶ reading
   ▲                  │                   │
   │                  │ 任意交互           │ 快捷键（小说立刻消失）
   └──────────────────┘◀──────────────────┘
                      ▲
                      └── reading 点击（渐进降级，不直接跳回工作界面）
```

要点：

- **快捷键永远是"减少暴露"的方向**：`reading → disguise`（正文消失）、`closed → disguise`（先藏起来）。任何状态下按它都不会让屏幕上多出小说内容。
- **点击是渐进降级**：`reading → disguise`（正文消失，但仍在伪装中），再点一下 `disguise → closed`（回到工作界面）。误点一下的代价只是"小说不见了"，而不是"屏幕跳回桌面"。
- **命令 `/stealth` 直达 `reading`**（要打字，不存在误触），并直接续读上次那本书。

## 后果

**得到：**

- 屏幕在任何时刻都像"AI 正在跑任务"，包括在读书的时候。这是本项目真正的目标形态。
- 不再有形态割裂：只有一种排版语言。
- 被看到时，暴露的是"一段中文文档输出"，而不是"一个小说阅读器"。

**代价：**

- **可读性下降**：等宽字体 + 行间插入工作痕迹行，读起来比书页累。这是用户明确选择的取舍（阅读舒适度让位于伪装可信度）。
- 需要维护"交错节奏"的确定性：同一章每次渲染必须一致，否则滚动时会跳动。

**不再做：**

- 衬线/居中/大留白的书页排版；
- "舒适阅读模式"开关（用户明确否决：只留一种形态，避免视觉不统一）。

## 备选方案与否决理由

| 备选 | 否决理由 |
| --- | --- |
| 保留书页 + 改进伪装壳，两者视觉统一 | 治标：书页形态本身就是暴露面，"统一视觉"救不了"一眼是小说" |
| 保留书页作为可选模式 | 用户明确否决；两种形态就是两种暴露面，且视觉永远统一不了 |
| 伪装壳里只放正文、不夹工作痕迹 | 满屏连续中文小说，被看到的人只会更好奇你在看什么 |
