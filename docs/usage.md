# 用法速查

面向使用者（而不是实现者）。设计理由见 `SPEC.md` 与 `docs/adr/`（尤其是 **ADR-0005**）。

## 只有一种阅读形态：伪装阅读

屏幕上看起来是「AI 正在跑一个长任务」——**你真实会话里的工具调用行**与小说正文交错出现，
共用同一套等宽排版，逐字长出来。

**没有书页模式**：衬线字体 + 居中 + 大留白的排版一眼就是小说阅读器，那本身就是最大的暴露面。

```
▸ Read  chapters/003.txt
   李四站在山巅，风从背后推来。
   他闭上眼，听见远处松涛如潮。
⏺ Read 第一章 风起  [3/512]
   风声越来越近，像有什么东西正在醒来。
```

小说段落以 DSH 自己的两种身份出现：**AI 回复正文**，或者**带左侧细竖线的工具输出内容**
（默认七成是后者）。章节标题伪装成一次 `Read` 工具调用 —— DSH 的消息流里没有"章节标题"这种东西。

## 两个状态

| 状态 | 屏幕上是 | 怎么进出 |
| --- | --- | --- |
| **DSH 真实界面** | DSH 本身 | **鼠标动 1px 或点一下**立刻回到这里（书单里除外） |
| **伪装阅读态** | 真实会话 + 小说正文交错 | 按 `Ctrl+Shift+Alt+Z` 进出 |

只覆盖**右侧会话区里 Tab 下面、输入框上面那一段** —— 顶部的标题栏和底部的输入框都是真的，
左侧栏也原样保留。三个"真的工作界面"部件都露在外面，掩护比整块盖住更厚。

## 怎么用

| 你想做的事 | 操作 |
| --- | --- |
| **开始看书 / 藏起来** | `Ctrl+Shift+Alt+Z`（同一个键来回切） |
| **回到工作界面** | **动一下鼠标或点一下**（书单里不行 —— 那儿只能用快捷键） |
| **翻页** | 滚轮 / 空格 / PageDown |
| **上下微调** | `↑` `↓`（一次滚十行正文，浏览器默认只滚两行） |
| **跳章** | `←` `→`（也可用 `[` `]`） |
| **换书 / 导入** | 按 `L` 打开任务列表；把文件**拖进窗口**即可添加 |

> **退出只认鼠标**：这样键盘可以全部留给阅读操作，不会读到一半被自己按没了。
>
> **书单是唯一的例外。** 书单要靠鼠标操作（点书名打开、点 `✕` 删除、拖文件导入），
> 所以在那里鼠标**不**收场 —— 否则手刚移到书名上界面就没了。书单里的出口是 `Ctrl+Shift+Alt+Z`。
> 注意书单里的**书名是明文的**，别让它长时间挂在屏幕上。

## 阅读进度

进度是**你读到哪儿**（已输出的字符占全章的比例），不是滚到哪儿。

- 关掉再打开，**精确停在**上次离开的地方，视口自动跟过去，从那儿继续长。
- 读到章末关掉，下次就停在章末；想继续按 `→` 翻下一章。
- 任务列表里每本书后面的百分比就是它。

## 任务列表（书架）

按 `L` 打开（再按一次关闭），它伪装成一份「最近的任务」：

```
recent tasks
▸ 云中记                      1/3 · 100%
· 山雨纪                      2/12 · 0%
+ attach file
```

每本书就是一个任务，进度就是百分比。**点整行** = 选中这本书接着读；点 `✕` 移除；拖文件进窗口导入。
点行右侧的 `≡` 展开它的步骤清单（见下）。

从列表回到正文**不会丢进度**：正文一直在后台继续输出，列表只是盖在上面。

### 快速跳章（步骤清单）

长篇动辄几百章，靠 `←` `→` 一章一章挪是不现实的。点书行右侧的 `≡`，展开这本书的**步骤清单**：

```
云中记                                     3/512
✓ 第一章 山雨                                 1
✓ 第二章 亭子                                 2
▸ 第三章 山雨欲来                              3
· 第四章 夜行                                 4
← back                     space page · l close
```

读过的打 `✓`，当前这条是 `▸`，右边是序号。滚轮 / 方向键 / 空格滚动，点任意一条直接跳过去。
打开时会**自动把当前章滚到视野中间** —— 否则几百章的书每次都要往下滚三百行。

点 `← back` 回书架，按 `L` 直接收起全部。

> 这是本项目里**单次暴露面积最大**的界面：它把全书的章节标题同时摆在屏幕上。
> 对认识这本书的人来说，章节标题比书名更容易认出来。用完记得退回去。

## 输出速度

节奏是**按行**分配的（不是全局匀速），三个旋钮都在 `src/client/typing.ts` 的 `DEFAULT_TEMPO`：

| 旋钮 | 默认 | 管什么 |
| --- | --- | --- |
| `charsPerSecond` | 18 | 一行之内逐字长出来的速度 |
| `minLineMs` | 90 | 一行占用的**下限**：短行也有"出现"这个动作，不会一闪就没 |
| `maxLineMs` | 2600 | 一行占用的**上限**：长段落不会让你干等 |

真实会话行（工作痕迹）固定走下限 —— 日志本来就该闪一下就走，不该拖住后面的正文。

觉得节奏不对，调这三个数就行，不用碰组件。

## 导入

- 支持 `.txt`（自动识别 UTF-8 / GBK）与 `.epub`（插图会保留；DRM 加密的书明确报错且不入库）。
- 书**只存在本机浏览器**的 IndexedDB 里，不上传、不进入工作区目录。

## 一个必须知道的取舍

伪装阅读牺牲了阅读舒适度：等宽字体、行间插着工作痕迹行，比在阅读器里读书累。
这是**刻意的取舍** —— 目标是"屏幕任何时候看起来都像在工作"，而不是"读得舒服"。
